# 简明中文术语与改写规范（C01）

2026-10-22，Pacific/Auckland。适用于现有三条路线。候选尚未应用；C02/C03/C04 在对应页面实施时结合业务条件定稿，C05 再记录实际用户理解度。

## 写法与层级

一个标题只说当前任务，例如“检查原图”“设置印刷尺寸”“保存最终文件”。任务名称是摘要，不能替代当前步骤标题。主说明用一句话交代下一步；需要保留的风险、前置条件和状态另起可见短句，不强行塞进一句，也不藏进悬停提示。

按钮使用“动词＋对象”，例如“选择此路线”“确认此 TIFF 通过检查”“完成此任务”。避免孤立的“通过”“完成”“确认”“重试”。操作对象必须是当前精确任务或结果；标签变得更明确不改变命令资格。审核控件继续使用 ReviewApprovalButton、TargetIdentity、IsGestureGuarded 和原 AutomationId。审核与保存的联合入口只能出现在现有协调器允许的位置，不能把所有审核按钮统一改成“确认并保存”。

说明用“发生了什么—保留了什么—下一步”组织。例如：“这份结果已通过审核，尚未保存到你选择的文件夹。无需重新处理图片。请核对文件夹后重试保存。”只有真实状态支持时才能这样写；不能向所有错误套用同一承诺。错误代码、路径和日志可展开，但原因、当前阻塞和合法下一步要直接可见。

标题目标 6–14 个汉字，按钮目标 4–12 个汉字，主说明目标 20–45 个汉字。这些是编辑目标，不是截断规则或测试阈值。“确认这张图通过检查”等准确长标签可以超出目标；必要时换行、调整布局并在真实缩放下复核。禁止为了凑字数删掉“不覆盖”“尚未核实”“不会自动保存”等限定。

称呼统一用“你”。保留产品、应用、格式名的既有写法；不要将枚举、错误代码、数据库值、AutomationId 或外部应用精确匹配词翻译。资源键保持稳定；正常状态不展示内部枚举名作为新文案，未知枚举的现有回退仅登记，不在本任务改行为。

## 术语表

| 概念 / 既有合同 | 推荐表述 | 首次出现的短解释 / 限制 |
| --- | --- | --- |
| Session / task | 任务 | 一次已导入图片的处理；返回首页不等于放弃任务。 |
| Workflow | 处理路线；后文可简称路线 | 准备设计素材、处理客户设计、生成打印 TIFF 三种用途；底层 WorkflowType 不改。 |
| Current step | 当前步骤 | 当前真正需要操作的步骤，不把未来步骤当作可执行按钮。 |
| Source / original | 原图；涉及文件时写原始文件 | 原件保持不变；准备出的 PNG 不是原件被替换。 |
| InputSnapshot | 导入时的原文件副本（技术详情保留 InputSnapshot） | PrintFlow 管理的输入副本，不能混作外部源文件。 |
| Enhancement | 增强清晰度 | 处理后仍要检查人脸、文字与异常细节，不承诺恢复真实细节。 |
| Background removal | 去除背景 | 处理可跳过不等于后续结果审核可跳过。 |
| Trim / crop | 裁切；具体动作写裁去多余边缘 / 调整裁切 | 使用裁切生成新结果后仍需审核；取消编辑不是放弃任务。 |
| ReviewRequired | 等待你检查 | 结果尚未通过人工检查；沿用11153“等待你检查”。 |
| Approved | 已通过审核 | 只指当前匹配结果的审核事实，不等于已保存或已完成。 |
| Rejected TIFF | 驳回此 TIFF | 沿用11154；保留先回收、再记录拒绝及之后显式生成的顺序。 |
| Delivered / saved | 已保存；只有已核实时写已核实保存 | 指向选定外部文件夹的保存事实，不能由内部 Approved 文件推断。 |
| Completed | 任务已完成 | 底层任务完成事实；不能由此推断外部文件存在。 |
| Previously saved | 有保存记录，当前文件待核实 | 11153/11154历史合同；TIFF份数按精确输出ID/尺寸统计。 |
| HistoryUnknown | 保存记录暂不可用 / 正在读取保存记录 | 没有已知的历史事实；不能写“曾保存”或“没有保存过”。 |
| StopRequested | 正在停止本次处理 | 请求已发出，不保证外部应用已停止或输出已写完。 |
| Stopped / failed | 已停止或失败 | 沿用11153；仅在已确认的终态显示，不替代停止中的投影。 |
| Take over | 在对应应用中接管 | 请求接管、正在交接与已移交分开；不强制关闭外部应用。 |
| Retry | 重试保存 / 重试此步骤 | 具体对象和现有资格须明确，不能把核实保存写成重试。 |
| Verify this save | 再次核实此次保存 | 查询同一次操作，不新增副本、不重新处理图片。 |
| Save another copy | 另存一份 | 新名称或新文件夹；不覆盖，也不抹掉先前待核实记录。 |
| Cancel page / draft | 取消本次选择 / 取消调整 | 只取消相应页面或编辑动作；先核对实际取消范围。 |
| Abandon session | 放弃任务 | 与移出最近列表不同；确认中保留文件和历史的实际处理方式。 |
| Print dimensions | 印刷尺寸；上限写最大印刷尺寸 | 复用11154，最大值不是精确的最终尺寸。 |
| mm | 毫米 | 物理印刷大小；不能替换成像素。保留宽度、高度、长边的区别。 |
| pixel | 像素 | 图片的细小方格；白墨内缩的单位是像素。 |
| White ink | 白墨 | 打印时垫在彩色图案下面的白色墨层；范围须结合本次设计检查。 |
| W1 | W1 白墨通道 | 用于打印的白墨信息；本次生成，不沿用源 PSD/PDF 专色或白墨通道。 |
| 0 / 1 / 2 px inset | 0 / 1 / 2 像素白墨内缩 | 0是不内缩，不是“不要白墨”；1/2为向内缩小。必须显式选择并记录对应图案分类理由，不默认选。 |
| PNG | PNG 图片 | 素材路线的图片结果；不能套用TIFF尺寸/白墨/多印刷尺寸提示。 |
| TIFF | 打印用 TIFF 文件 | 保留格式名；生成、校验、人工审核、保存是独立动作。 |
| PPI | PPI（每英寸像素数） | 保留300 PPI生产合同；不把PPI任意替换成DPI。 |
| CMYK | CMYK 印刷色彩模式 | 屏幕近似预览不是打印色彩保证。 |
| PSD / PDF | PSD / PDF 源文件 | 先按真实准备结果检查；PDF页数与第1页、300 PPI、尺寸/像素不能被省略。 |
| Colleague correction | 准备修正副本 / 交给同事 / 导入修正文件 | 三步分开；本地准备不等于发送成功，导入后仍需必要审核。 |
| Environment readiness | 环境检查 / 当前检查结果 | 历史检查通过不代表持续生产就绪；门禁与自动化锁照常生效。 |

## 资源、格式和辅助名称

以 COPY_INVENTORY 中的完整占位符为准，逐项保留索引、出现次数、对齐及格式，例如 `{0:0.##}`、`{1:0.#}`。语序可调，参数的业务含义不能交换。路径、文件名和用户备注是运行时数据，不在资源候选中编造值，不把路径结尾的标点纳入实际文件名。`Strings.resx` 与 `Strings.zh-CN.resx` 的键集合和格式合同一致；本任务保留英文现值，不增加英文真人验收要求。

格式名、300 PPI、CMYK、W1、0/1/2、毫米/像素、乘号、文件对话框过滤器、换行、百分数格式及多尺寸数量均逐项核对。父计划的示例也是候选，不可脱离最新真实状态直接贴到资源里。

可见文字与 AutomationProperties.Name/HelpText、代码创建控件的 SetName/GetNameCore 要一起核对。动词与对象保持一致；保留结果身份、任务身份和路线限定，不读成“已保存”却实际只有审核。不要以冗长辅助名称弥补缺失的可见风险；AutomationId 与业务控件类型不改。当前 SOURCE_REGISTER 只登记静态绑定/调用位置，实际读屏、Tab、Enter/Space 与真实DPI仍待相应页面实施后验证。
