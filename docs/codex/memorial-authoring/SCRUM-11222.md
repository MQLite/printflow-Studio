## Implementation and validation progress

- `AiPromptEditor` projects known text/image nodes, emits frozen document edits and delegates image clicks using stable PartId/SlotId. It owns no file picker or persistence. `ReferenceLabels` is a host-provided presentation dictionary so A5 can refresh role/upload labels without replacing the document or caret; fallback text is localised in the existing resource files.
- WPF undo serializes embedded controls and drops arbitrary record-valued Tag/delegates. Tokens therefore carry a serializable string PartId; a projection-owned reference registry and delegated button event restore the same actionable reference after undo. No typed labels are parsed into bindings.
- Paste is text-only, grouped into one undo operation and inserted directly into a Run: TextRange.Text was experimentally shown to rewrite lone LF into CRLF. Tests cover mixed LF/CR/CRLF, combining characters, spaces and template-like literals. Drag/drop is disabled to keep foreign rich objects outside the node projection.
- Test-harness ruling: WPF's native text undo manager requires a laid-out editing template; offscreen tests now measure/arrange before editing. Rich TextInput is dispatcher-queued and tests drain the Background work. Native Enter explicitly requires real keyboard focus, so offscreen paragraph tests use its document editing primitive rather than claim physical keyboard evidence. Button Enter activation is tested through actual routed key events.
