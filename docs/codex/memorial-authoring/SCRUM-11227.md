## Behavior and seams

- Workflow exposes `IMemorialTextLayout.Arrange(draft, canvas, styles)` and returns immutable `MemorialTextLine` records. WPF objects remain in Infrastructure. No packages, request schema changes, font downloads or production approvals are introduced.
- Only the exact values from B1 `TextInputs` can become text. The required name, date values and nonempty date labels need explicit styles. Labels use `date-label:<text confirmation key>` and share the corresponding date's exact-content/label/format confirmation. Optional absent dates omit both date and label. Unknown or duplicate style keys fail.
- A6's current content confirmation and `CanConfirm` checks are required for each consumed field; unresolved final-prompt reconciliation blocks arranging. Source text is never inferred from a manually edited prompt. The raw `12/06/1039` survives after explicit date-format/year confirmation.
- TextFormatter uses installed font families, ideal metrics, native shaping, fallback fonts, advances and attachment offsets. Missing visible glyphs, malformed UTF-16, hidden unsupported control text and uninstalled families fail with a structured issue and field key. User strings cannot become font paths or remote font addresses. A missing name semantic or mandatory name without visible ink cannot yield empty successful output.
- A flat layer keeps explicit CR/LF/CRLF, NEL, Unicode line and paragraph separators, spaces and tabs. It measures trailing spaces and a final empty line. It never inserts wrapping or rewrites line endings. A multiline/tabbed arc requires the user to choose a single-line or flat layout.
- Arc geometry applies rigid transforms to shaped clusters, merging Unicode grapheme boundaries so a combining sequence, surrogate pair or shaped ligature cannot be split by a UTF-16 character loop. The same literal string and font size remain in the result. Nonzero winding retains overlapping strokes and Arabic joins. Derived radii, transforms and final geometry must remain finite.
- Infrastructure's internal `Prepare(line)` returns frozen, millimetre geometry and read-only source-cluster metadata. B3 must reuse this seam after verifying the frozen draft and source manifest, so measurement and actual drawing use the same outlines. The editable Domain DTO remains text/style data, without WPF types or persisted machine-specific glyph IDs.
- B1 checks the full reserved text rectangle against the product canvas/safe circle. Actual ink plus logical advances/line height must fit that rectangle. Overlong text reports `TextDoesNotFit`; missing glyphs report `MissingGlyph`. Neither causes truncation or automatic font shrinking.

## Decisions and limits

- Reuse the existing feature branch and directory under desktop workspace guidance. There is no separate directory isolation from another editor.
- Center fixed-size text within the supplied bounds. The supported arc is the upper, single-line arc, at most π radians. Other arc directions, automatic wrapping and interactive style controls remain future work; multiline text can use explicit flat lines now.
- Use a configurable default 2 mm font-size floor, maximum 4096 UTF-16 units per layer (configuration capped at 16384), and 32 style inputs per call. These are bounded-work/style parameters, not a universal printing standard or proof of readability. Changing the floor is explicit; the engine never changes the requested font size.
- The synchronous port runs shaping on the current STA or a joined dedicated STA worker. B3's renderer may call it on its own STA. No visible window, desktop input or resident service is created.
- Paragraph direction uses Windows `GetStringTypeW` bidi categories, the first strong character outside isolates, and explicit direction marks/embeddings/overrides; it is resolved separately for each explicit source row. The sole new native entry point is read-only and declared in the existing `Automation/NativeMethods.cs`, as required by the architecture boundary. OS Unicode classification and font support bound uncommon scripts; no hand-maintained script table or new font library is claimed. Source control characters are retained for WPF to apply, not stripped.
- WPF may emit an emergency line boundary even with wrapping disabled. A formatted row must consume the full explicit source row; an implicit break is rejected before accumulating another row or generating geometry. There is no hidden wrapping at the configurable character limit.
- Split the dedicated adapter into validation, formatting callbacks and geometry partial files to keep the memorial-specific implementation navigable. No general typography framework or new shared state was added.
