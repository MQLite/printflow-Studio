Keep workflow rules in their existing Domain/Workflow owners.

- Processing uses actual runtime state/application/phase and an indeterminate indicator. Stop/takeover remain the existing commands and semantics. Never invent percent complete or auto-approve/auto-run the next step. Reloaded processing sessions cannot change route.

- Print summary separates requested size from pixel-rounded actual millimetres and output pixels. Display uses at most two decimal places; raw custom input, validation, size restore and arithmetic are unchanged. Existing F6 precision defect is not repaired by formatting the summary.
- Custom-size mode collapses presets into an accessible disclosure so its current input remains above the fold at 1000x700 DIP. Presets stay available. Print preview fits independently of review zoom without mutating the stored review viewport; review tools reappear on review pages.
