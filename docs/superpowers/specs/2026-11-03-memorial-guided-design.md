## 1. 意图与依据

让操作者按小步骤把需求变成一份可核对的设计说明，再组装提示词与处理计划。参考图在相关步骤始终可见；用户明确哪些元素沿用、哪些需要修改，以及结果应做成哪种成品。

已读取历史对话文字：制作T恤设计、设计圆形徽章、修改T恤设计、啤酒瓶贴纸设计、制作旗帜文字设计、图片风格转换、制作T恤图案、修改图案设计。设计依据是其中明确提出的要求与返工点；未把历史助手宣称的生成成功当作质量验收，也未使用客户附件制作本轮示意图。

主要需求：面部、表情、衣服和胸章保留；花叶与原装饰不增减；姓名、日期、大小写及符号准确；修改只影响指定对象；同一设计可转为其他成品；透明区域和清晰度需要真实检查。

本次只覆盖同一人物的纪念设计。多人合成、自动人脸识别、自动抠图、复杂装饰自动拆层、批量生成、付费模型接入、生产 TIFF 和安装配置不纳入本稿。

## 3. 完整引导流程

| 阶段 | 操作者完成的事项 | 通过条件与界面反馈 |
| --- | --- | --- |
| 1 选择任务 | 选择 T恤或徽章，选择新建/参考创作/修改/转换 | 转换必须选定具体来源版本；摘要显示成品与来源，不能默认采用“最新图” |
| 2 选择参考 | 逐份选择文件并标明人物来源、装饰原稿、版式参考或风格参考 | 人物来源必填；同一文件可有多个明确角色；被引用文件缺失时定位到对应附件 |
| 3 确认保留 | 对照原图确认人物、饰物、装饰、背景的内容与位置权限 | 每个采用的元素均有保留/修改意图；冲突需要选择；保真所需素材未就绪时显示具体缺口 |
| 4 核对文字 | 分别填写姓名、日期、标签、纪念语；对照原始输入逐字核对 | 姓名与日期分别确认；选择日期格式；有修改时明确显示差异；可选择不显示日期 |
| 5 设置成品 | 确认设计区域、布局、配色、衣服底色或徽章安全区，检查裁切 | 关键内容满足所选布局与可见范围；超界、字过长或保留冲突均未解决时不能完成本步 |
| 6 检查描述 | 查看需求摘要、完整提示词、附件用途与处理分工 | 所有必填项与确认就绪；列出本轮生成/沿用/排版内容；可以保存草稿或复制说明 |
| 生成与接收 | 在可用通道明确开始一次任务；观看真实状态或走人工交接 | 按现有请求/尝试身份追踪；不以模型文字或进度动画认定成功 |
| 结果对照与转换 | 原图对照、逐项核对人物/装饰/文字/版式，接受或按范围修改 | 所有必需检查完成才能接受素材；可另建另一成品版本；仍需进入现有素材/印刷流程 |

左侧导航显示“已完成 / 当前 / 待核对”；当前页只突出一类决定。返回已完成步骤保留输入，变更影响哪些确认项会先显示，再把相应项改为待核对。右侧摘要区分“已确认”和“待确认”，高级完整提示词按需展开。正文、焦点、按钮与反馈沿用当前 WPF UI 的资源和可访问性约定。

## 4. 参考对照与保留规则

### 4.1 附件角色

| 角色 | 用途 | 确认内容 |
| --- | --- | --- |
| 人物来源 | 提供本人照片、表情、服饰与饰物 | 指定具体图片；选择使用整张照片或经用户确认的裁切/透明素材 |
| 原样装饰 | 沿用花框、花叶、纹样、奖章等既有素材内容 | 指定原稿或可用素材；确认采用范围和可移动/缩放权限 |
| 版式参考 | 参考人物、标题、边框的布局关系 | 明确只参考排布，或另外声明某个素材要原样沿用 |
| 风格参考 | 参考色调、纹样、质感 | 不自动成为需要原样复制的对象；文化、国旗或宗教元素仅采用明确选择 |

每张卡显示缩略图、角色和用途，并可“放大对照”“更换”“移除”。界面使用图1/图2等可读名称，内部绑定稳定附件身份；改变顺序或文件名不能把人物来源错绑到另一张图。

### 4.2 内容和几何权限分开记录

| 对象 | 内容默认建议 | 可用的几何选择 |
| --- | --- | --- |
| 人物照片 | 原照片沿用；保留面部、表情、衣服和指定饰物 | 等比缩放、移动；裁切范围另行确认；不做拉伸变形 |
| 原有花框/装饰 | 原样沿用，不新增、移除或重新绘制内容 | 整体等比缩放、移动；拆分、旋转或调整相对位置须明确允许 |
| 新增背景/装饰 | 可以生成，由用户选择风格和颜色 | 适配当前成品；不得覆盖需要保持可见的对象 |
| 姓名与日期 | 使用已核对的精确文本 | 改变排版、换行或弧线需要版式确认；文字内容保持原文 |

“原样保留”是处理意图，不是勾选后已经证明图像保真。目标处理路线采用原照片/原装饰素材沿用与排版合成，AI 只负责明确授权的新内容；最终精确文字采用可编辑文字层排版。此受限合成能力尚未接入，必须作为后续实现的必需能力，不得用生成提示词冒充已完成的像素保护。

素材分为“可直接沿用”“需要准备并确认”“仅供参考”。已有不透明人物照片可以在已确认的照片框内保留背景使用；需要去背景时，用户提供/经现有素材准备或人工处理得到可用素材，再确认结果。本稿不包含自动抠图或从整张复杂成品中自动拆出花框。装饰只有扁平参考图且不能直接沿用时，应明确补充可用原稿，或由用户改为“风格参考、允许重绘”；不自动降低保留要求。

严格保留模式的生成/合成入口依赖素材就绪和相应处理能力。能力缺少时保留草稿、说明缺失项，允许复制完整需求和人工交接；不声称能够自动得到保真的完整成品。纯文字/版式修改且全部素材可用时，处理计划可以只做排版合成，无须再次生成图片。

若用户选择允许人物艺术化重绘，单独说明面部可能变化，保留要求变为人工核对项；这不是当前两种纪念成品的默认处理路线。切换该模式需要显式确认并形成新版本。

## 5. 姓名与日期核对

页面左侧展示原始输入/来源说明，右侧展示本版本拟用文本。未经用户核对的 OCR 或推断只能是候选，不写成已确认文字；本轮不依赖 OCR。文本字段采用用户输入原文，保留字母大小写、重音符、标点、空格和用户指定换行。

| 字段 | 交互与规则 |
| --- | --- |
| 姓名 | 独立大字号输入框与排版预览；确认“姓名逐字核对完成”；疑似拼写问题只提醒 |
| 出生日期 | 显式选择日/月/年等来源格式；显示日期解释，保留用户确认的最终展示格式 |
| 离世日期 | 与出生日期分别确认；若两者作为生卒日期且先后矛盾，需修正或清空对应字段 |
| 日期不详 | 可选择“不显示/仅显示年份”；不得为缺失字段编造数字 |
| Sunrise / Sunset 等标签 | 作为可编辑的精确文字，采用用户选定语言；不擅自翻译或替换 |
| 纪念语 | 可选；原文输入与排版预览，字符缺字时提示选择支持的字体 |

例如 `12/06/1039` 触发“请核对年份”的提醒，不自动改为 `1939`。用户改动后展示 `1039 → 1939`，重新确认日期；若用户明确核实异常年份，也可记录确认继续。日/月顺序不明时先选择解释，不能仅凭语言猜测。

姓名确认与日期确认分别保存，不能由一个泛化“全部正确”复选框替代。修改某项精确文字、日期解释、来源文本或标签会撤销对应确认；只改背景颜色不会撤销姓名确认。改字体/换行不会改文字原文，但需重新看排版预览。

精确文字在最终文字图层中排版；需要 AI 装饰留白时，生成提示词提供留白要求。若用户选择包含 AI 绘制文字的人工模式，界面必须保留逐字结果核对，不把“已要求原样”写成“字已正确”。

## 6. 两类成品布局

以下是本项目建议采用的历史常用预设，需要在每个版本中确认，不是通用行业标准。

| 项目 | 纪念 T恤 | 圆形徽章 |
| --- | --- | --- |
| 示例设计区域 | 280 × 390 mm，28:39 竖向构图 | 画布外圆 86 mm，内容安全区直径 72 mm |
| 背景/外围 | 图案外部及指定间隙透明；可用黑/白衣底预览 | 外圆之外透明；外圆与安全区之间单侧 7 mm 环带只延伸已允许的背景/边缘装饰 |
| 关键内容 | 人脸、指定饰物、姓名、日期与需完整显示的装饰 | 同样的关键内容均需在安全区内完整可见；受保护内容不能用于包边 |
| 布局选择 | 上姓名/人物/下日期，或用户明确的原稿布局 | 上姓名弧线/中间人物/下日期；长姓名可用两行或其他确认后的布局 |
| 衣服/底色 | 黑色、白色或自选，作为对比预览条件 | 中性底或用户选择背景；明确外圆透明边界 |
| 警告 | 切边、装饰遮挡、原图像素不足、文字难以排下 | 关键内容出安全区、字过长、裁切触及人脸/饰物、保留规则冲突 |

徽章示例中 7 mm 由 `(86−72)/2` 得到。实际设备模板的裁切、包边与成品口径需要单独确认，不能把画布外圆当作设备已验证的成品口径。布局图的安全区线只是辅助，不进入导出的图案。

自动适配只在已允许的移动和等比缩放范围内给出候选布局。姓名过长时提供换行、调整弧长或换布局；不省略姓名、删除日期或无限缩小字体。具体模板字号和留白作为视觉实施参数，经实际预览验证；本稿不宣称统一的印刷最小字号。

新增白色描边是单独的用户选择，与“原装饰内容保留”分开；不直接改写原素材。衣服底色预览不会烘焙到透明图案，也不会自动替用户选择生产白墨。毫米与比例是设计目标，最终像素、透明通道和后续打印尺寸必须通过真实文件及既有流程确认。

## 7. T恤与徽章相互转换

1. 在已保存的设计版本上点击“制作另一种成品”，明确显示来源，例如 `纪念 T恤 v1`。
2. 新建目标成品草稿，记录父版本；复制已确认的照片/装饰来源、内容保留规则、姓名与日期快照。原成品及其文件保持不变。
3. 切换目标预设，重新确认画布、安全区、人物与装饰的位置、文字排版和背景延伸。每项显示“沿用 / 待核对 / 需要调整”。
4. 在并排预览中标出变化：构图、移动与等比缩放、弧形文字、包边环带、透明边界。字与人脸的原文/原素材单独列为沿用项。
5. 若权限不足以完成适配，先给出“缩小整体”“另选布局”“明确允许装饰重排”等选择；不静默裁掉花叶或胸章。取消转换只丢弃新草稿，来源不变。
6. 姓名/日期内容未改时保留原来的文本核对记录，但目标排版仍需确认；文字内容有改则对应项重新核对。对某个成品改名或改日期默认仅影响该版本，不自动同步其他版本。
7. 生成新的需求与处理计划。只需重新排版时复用原素材，不要求重新生成整张人物图；需要新背景时只生成该新增部分。
8. 保存为目标版本并对照检查，例如 `圆形徽章 v1 · 来源：纪念 T恤 v1`。返回原 T恤时其内容和确认状态不变。

同一项目可有两类成品，每个版本有独立状态与结果；每个自动生成尝试仍只对应一张图片。批量生成与跨版本自动同步不在本轮范围内。

## 8. 提示词如何逐步组成

内部需求包含：任务/成品、附件角色、素材就绪状态、内容保留要求、几何权限、精确文字与确认记录、样式、产品布局、输出意图、来源版本。向导每步只更新相应片段，右侧先显示中文摘要；最终冻结具体附件与本轮需求快照。

提示词按以下稳定顺序组成：`任务 → 参考角色 → 必须沿用 → 本次可变 → 新增生成内容 → 构图/留白/颜色 → 输出要求`。同时生成单独的“处理计划”，区分本地沿用、文字排版和 AI 生成，避免把所有内容都要求模型重绘。

严格保留模式示例：

```text
设计目标：纪念T恤独立图案，按已确认的280×390mm构图意图制作。
参考用途：图1参考已确认版式；图2为沿用的人物原照片；图3为沿用的原花框素材。
沿用素材：人物面部、表情、衣服和胸前饰物；原花框与花叶内容。
本次生成范围：仅生成用户选择的新背景装饰，并为人物、姓名及日期预留空间。
配色：已确认的蓝白配色；新增装饰不得覆盖需保留区域。
图片输出：新增图层素材，按明确的构图与透明区域要求提供一张原始结果。
```

相应本地处理计划为：沿用人物和原花框 → 应用已确认的移动/等比缩放 → 排版已确认姓名及日期 → 合成预览 → 逐项核对。AI 输出的新增图层不等于完整成品，不直接作为已审核的纪念图案导入。

用户手动编辑完整提示词时保留该文本；返回修改字段会显示受影响片段，提供“保留手改文本并重新核对 / 用字段重建”选择，不静默覆盖。只要人工文本与保留范围或生成分工冲突，就需要澄清并重新确认，不能绕过结构化保护与文字核对。

## 9. 生成、接收、核对和修改

- 生成前展示“本次生成哪些内容、沿用哪些素材、之后还需哪一步”。本地合成与远端生成分别标识；素材/合成/通道能力未具备时给出具体原因及人工交接。
- 沿用当前请求/尝试/版本、必要附件完成回执、单次提交、停止和重启恢复合同；编辑草稿不改变已提交尝试。
- 输出交接继续按现行 MCP/Drive 设计，不恢复浏览器控制下载。新增图层、合成预览、候选接受、导入和生产审批是不同状态。
- 接收后显示原照/原装饰与候选的并排查看、放大与背景切换。自动检测可以验证文件/透明通道/几何边界；面部、饰物完整性、装饰内容与文字可读性仍有明确人工核对。
- 必需核对分组：人物与指定饰物；原装饰；姓名与每个日期；成品排布与安全区；透明边界。缺项不能接受本版本。
- “只改文字 / 只改配色 / 调整位置 / 重选生成背景”产生新版本与差异摘要，保留其他要求。只改文字优先重新排版；不重绘整张人物图。
- 接受素材后进入已有素材准备/工作流选择，再进行实际尺寸、印刷风险、审核和保存。接受设计不等于生产文件已审核或已保存。

## 10. 确认失效规则与异常路径

| 变化/问题 | 需要重新核对的事项与操作 |
| --- | --- |
| 更换人物图 | 人物来源、保留范围、所有成品的人物布局；每个版本独立提示，不直接改旧结果 |
| 更换原装饰 | 原样沿用范围、遮挡与布局；文字内容确认可以保留 |
| 修改姓名/日期 | 对应字段确认、文字排版与最终需求；其他已确认文本不无故清空 |
| 改配色或预览衣底 | 样式和可读性；保持姓名/日期原文与人物来源确认 |
| T恤转换徽章 | 新版本的规格、安全区、文字排布与布局确认；原版本不失效 |
| 被引用附件移除 | 显示对应缺失角色与片段，补足或明确取消该引用后继续 |
| 保护要求和裁切冲突 | 阻止确认布局，选择整体缩放/换布局/明确改变权限；不自动减少保留范围 |
| 字体缺字或日期格式不明 | 定位到字体/字段解释，确认后再继续 |
| 通道失败、停止或重启 | 保留已确认需求、附件与人工交接；不自动再提交；不丢弃已收到的候选 |

## 11. 实现边界与交付前验收情景

现有 `PromptTemplateService` 只有三个平面模板字段；现有请求协调器具备草稿、附件快照和尝试冻结机制。人物/装饰按元素保留、可编辑精确文字层、受限合成、跨成品版本与上述完整 UI 均是待实现能力，不能在本稿中写成已接通。本设计优先复用原服务资格、附件身份和请求生命周期；需求结构升级时须保留旧版本数据的读取与语义，不直接把旧模板解释成已经完成新核对。

实施前应据此另行拆分能力与 UI 工作；具体图像/字体库和控件实现由实施规划选择，必须具备上述能力门禁。不能让一个声称“原样保留”的 UI 在只具备整图生成的后端上可直接自动提交。

后续验证至少覆盖：

1. 人物照片带胸章，T恤和徽章中均完整可见，照片不因改名而重新生成。
2. 装饰原样沿用且不允许拆分时，转换遇到冲突能暂停并提供布局选择。
3. 只有扁平参考图、没有可沿用装饰素材时，显示缺口并提供准备素材/改为参考的选择。
4. 异常年份提示、日/月歧义和先后矛盾各走正确路径；用户修正后撤销对应确认并保留差异。
5. 长姓名、重音字符、原始拼写与不同标签语言不被截断或自动纠正。
6. 徽章的关键内容在72mm安全区内；86mm外圆之外透明；辅助线不进入输出。
7. T恤转徽章仅改新版本，姓名照片沿用，版式重新核对；取消不影响来源版本。
8. 用户编辑提示词后再改字段，不静默覆盖手改内容或绕过保留要求。
9. 自动通道不可用仍能保存与复制完整需求；没有伪造上传、生成、合成、审核或导入成功。
10. 演示图片、草稿、真实结果、素材接受和生产审核明确区分；实机/真人/印刷未验收时保持待验收。
